Kevin, Lord of the Hollow Keep, has already won — the valley kneels, the moon pays rent — and all he needs now is the hero's name on one last page. A 100-word villain monologue in which the tiredness lives in the pauses, the lost thread and the small deflections, never in a plain announcement: the script, the raven with its amendments, the drowned bell, and a chair that has been waiting longer than the hero has lived.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes exactly 100 words (535 characters) to `entry.txt`, deterministically, standard library only.
